# آیکون‌هایی که هنوز لازم است

این‌ها جاهایی هستند که بازی هنوز ایموجی یا علامت ساده نشان می‌دهد. هر دسته یک شیت ۴×۴ است، دقیقاً مثل `icons-atlas.png` (۱۲۵۴×۱۲۵۴، پس‌زمینه‌ی شفاف، هر خانه یک آیکون، وسط خانه، با فاصله‌ی خالی دور آن).

**نسخه‌ی قفل دستاوردها لازم نیست**: بازی خودش آن را خاکستری می‌کند. فقط نسخه‌ی باز شده را بسازید.

## سبک (اول هر پرامپت)

```text
Game icon sheet for "Grid Rush", a Persian tilework (kashi) board game. Match this exact style: collectible 3D
objects of polished gold leaf with turquoise and lapis enamel, haft-rangi floral inlay (khatai flowers), small
turquoise cabochon gems, soft top-left light, crisp edges, no outline glow. Each object centred in its own cell
of a 4x4 grid, 1254x1254 px, fully transparent background, generous empty margin around each object, no text,
no numbers, no letters, no calligraphy. Readable at 32 px: one bold silhouette per icon.
```
