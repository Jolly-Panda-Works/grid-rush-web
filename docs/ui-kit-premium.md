# آرت کاشی‌کاری ایرانی، نسخه دوم

بازطراحی بر اساس بازخورد کاربر و مرجع تصویری آیکون‌های بازی با تم مصر انجام شد. مرجع صرفاً معیار جزئیات، پرداخت و حجم بود؛ نقش‌مایه‌ها ایرانی هستند.

- گالری: `/ui-kit-premium/index.html`
- مسیر فایل‌ها: `client/public/ui-kit-premium/`
- ۱۶ آیکون، ۲۴ آواتار، ۲۴ کاشی و ۱۲ قاب / کنترل: مجموع ۷۶ طرح در چهار شیت PNG.
- `manifest.json`: مسیر شیت‌ها، ابعاد واقعی و محدوده نمایش هر المان بر حسب پیکسل.
- `prompts.json`: پرامپت‌های واقعی و نام ابزار داخلی `image_gen`.
- `frames-atlas.png` نمونه اولیه قاب‌هاست؛ نسخه منتخب گالری `frames-atlas-v2.png` است.

فایل‌های اصلی با شفافیت تولید و بدون تغییر پیکسل در پروژه کپی شده‌اند. گالری هر المان را با viewport برداری از شیت اصلی نمایش می‌دهد؛ PNG مجزای هر آیتم هنوز استخراج نشده است. چینش شیت تولیدشده کاملاً یکنواخت نیست؛ از محدوده‌های manifest استفاده کنید، نه تقسیم خودکار تصویر به سلول‌های مساوی.

این نسخه آرت تصویری جدید است، نه بازنویسی صفحات React. مجموعه قبلی SVG برای مقایسه حفظ شده است. همه حالت‌های تعاملی و کل موارد مسترپرامپت هنوز با آرت جدید بازتولید نشده‌اند.

بازسازی گالری از دارایی‌های موجود:

```sh
node tools/build-premium-gallery.mjs
```

این دستور تصویر تازه تولید نمی‌کند و API فراخوانی نمی‌کند. تولید تصاویر توسط ابزار داخلی انجام شده است.
